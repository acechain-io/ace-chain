# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities to **security@acechain.io**.
Do not disclose vulnerabilities through public issues before coordinated review.

Include:

- Affected component, crate, or file
- Reproduction steps or proof of concept
- Expected impact
- Suggested mitigation, if available

We will review reports as quickly as possible and coordinate remediation before
public disclosure when appropriate.

## Scope

Security-relevant areas include consensus safety, validator admission, transaction
authorization, runtime execution, RPC handling, cryptographic verification,
wallet and identity integration boundaries, and persistence or rollback behavior.
